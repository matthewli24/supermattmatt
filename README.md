## Dependencies
* React   
* Firebase      
* SASS  
* npm               


## Building the app
```
$cd </path/to/app>
$npm install
$npm start
```

## Hosting on Firebase
```
$npm run build
$firebase init (when prompt about 'public', name it 'build)
$firebase deploy
```
